# Последовательность создания проекта IT-Tools

## Общий план разработки

Проект создаётся в 12 фаз, от фундамента до финального тестирования и деплоя.

## Фаза 1: Фундамент проекта

### Задачи:
1. Создать структуру директорий согласно плану
2. Настроить .htaccess для Front Controller паттерна
3. Создать index.php как точку входа
4. Настроить подключение к базе данных (config/database.php)
5. Создать SQL скрипт структуры таблиц (sql/schema.sql)
6. Создать SQL скрипт тестовых данных (sql/test_data.sql)

### Результат:
- Базовая структура проекта
- Роутинг через Front Controller
- Подключение к базе данных
- Готовая структура БД

## Фаза 2: Слой базы данных

### Задачи:
1. Реализовать класс Database.php с PDO подключением
2. Реализовать класс Section.php с CRUD операциями
3. Реализовать класс Lesson.php с CRUD операциями
4. Добавить JSON кодирование/декодирование для контента уроков
5. Реализовать логику валидации (дубликаты, формат slug, порядковые номера)

### Результат:
- Готовые модели для работы с БД
- Валидация данных
- Обработка JSON контента

## Фаза 3: Базовые шаблоны

### Задачи:
1. Создать header.php с адаптивным header и переключением темы
2. Создать footer.php с адаптивным текстом footer
3. Создать 404.php страницу ошибки
4. Настроить базовую структуру CSS с OKLCH переменными
5. Реализовать Mobile First базовые стили (320px-599px)

### Результат:
- Базовые шаблоны для всех страниц
- Фундамент CSS с переменными
- Страница ошибки 404

## Фаза 4: Основное приложение

### Задачи:
1. Реализовать HomeController для отображения разделов
2. Создать home.php шаблон с карточками разделов
3. Реализовать LessonController для отображения уроков
4. Создать lesson.php шаблон с секциями theory/tests/lab
5. Добавить JavaScript для интерактивности тестов (мгновенная обратная связь)
6. Реализовать кнопки навигации (предыдущий/следующий/оглавление)

### Результат:
- Главная страница со списком разделов и уроков
- Страницы уроков с контентом из БД
- Интерактивные тесты с мгновенной обратной связью

## Фаза 5: Авторизация в админке

### Задачи:
1. Создать форму входа (templates/admin/login.php)
2. Реализовать AdminController с логикой авторизации
3. Настроить управление PHP сессиями
4. Добавить защиту маршрута /bod
5. Hardcode credential'ов (bodryakov.web / Anna-140275)

### Результат:
- Форма входа в админ-панель
- Авторизация через PHP сессии
- Защита админских маршрутов

## Фаза 6: Админ-панель

### Задачи:
1. Создать админ dashboard (templates/admin/dashboard.php)
2. Реализовать список разделов с кнопками редактирования/удаления
3. Реализовать список уроков с кнопками редактирования/удаления
4. Добавить навигацию к формам разделов/уроков

### Результат:
- Главная страница админ-панели
- Списки разделов и уроков с управлением

## Фаза 7: Управление разделами

### Задачи:
1. Создать форму раздела (templates/admin/section_form.php)
2. Реализовать CRUD операции в SectionController
3. Добавить валидацию для title, slug, order

### Результат:
- Полноценное управление разделами

## Фаза 8: Управление уроками

### Задачи:
1. Создать форму урока (templates/admin/lesson_form.php)
2. Интегрировать CKEditor 5 CDN с кастомной панелью инструментов

8. Реализовать проверку дубликатов (смешанный подход)

### Результат:
- Полноценное управление уроками
- CKEditor 5 с ограниченным функционалом
- Программный конвертер тестов

## Фаза 9: Продвинутый CSS

### Задачи:
1. Реализовать адаптивные точки перелома (600px, 1000px, 1500px, 1920px)
2. Добавить современные CSS возможности (cascade layers, nesting, container queries)
3. Реализовать переключение светлой/тёмной темы
4. Добавить продвинутые эффекты текста где уместно

- Переключение тем

## Детали реализации по файлам

### Корневые файлы
- **.htaccess**: Перенаправление всех запросов на index.php кроме статических файлов
- **index.php**: Front Controller, разбор URL, подключение контроллеров

### Конфигурация
- **config/database.php**: Hardcode credential'ов, PDO подключение

### Публичные ресурсы
- **public/css/styles.css**: Все стили, OKLCH переменные, Mobile First
- **public/js/main.js**: Основная интерактивность, переключение темы
- **public/js/tests.js**: Логика тестов, мгновенная обратная связь

### Шаблоны
- **templates/header.php**: Адаптивный header, тема, навигация
- **templates/footer.php**: Адаптивный footer с авторской информацией
- **templates/home.php**: Карточки разделов с уроками
- **templates/lesson.php**: Страница урока с theory/tests/lab
- **templates/404.php**: Страница ошибки с кнопкой на главную

### Админ шаблоны
- **templates/admin/login.php**: Форма авторизации
- **templates/admin/dashboard.php**: Списки разделов и уроков
- **templates/admin/section_form.php**: Форма раздела
- **templates/admin/lesson_form.php**: Форма урока с CKEditor
- **templates/admin/test_converter.php**: Конвертер тестов

### Контроллеры
- **controllers/HomeController.php**: Логика главной страницы
- **controllers/LessonController.php**: Логика отображения уроков
- **controllers/AdminController.php**: Логика админ-панели
- **controllers/SectionController.php**: Логика управления разделами

### Модели
- **models/Database.php**: PDO подключение, базовые запросы
- **models/Section.php**: CRUD для разделов, валидация
- **models/Lesson.php**: CRUD для уроков, JSON обработка

### SQL скрипты
- **sql/schema.sql**: Создание таблиц sections и lessons
- **sql/test_data.sql**: Тестовые данные (1 раздел, 1 урок)

## Примечания к разработке

### Важные моменты:
- Все файлы в UTF-8 без BOM
- Комментарии на русском языке в каждом файле
- Методология БЭМ для CSS классов
- Data-атрибуты для JavaScript
- OKLCH для всех цветов
- Grid вместо Flex
- Mobile First подход

### Проверка после каждой фазы:
- Функциональность работает
- Код соответствует ТЗ
- UTF-8 кодировка корректна
- Комментарии добавлены
- Следующая фаза может начинаться

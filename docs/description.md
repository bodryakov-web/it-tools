# Описание проекта IT-Tools

## Общее описание проекта

IT-Tools — это full-stack веб-приложение для образовательного курса по IT-инструментам для бизнеса. Приложение создано на чистом PHP без использования фреймворков, с базой данных MySQL (хранение контента в формате JSON) и фронтендом на чистом HTML, CSS и JavaScript. Для редактирования контента используется CKEditor 5.

## Основные функциональные возможности

### 1. Структура курса
- Разделы (примерно 5 разделов)
- Уроки внутри разделов (примерно 5 уроков в каждом разделе)
- Динамическое формирование страниц уроков из JSON-данных и единого шаблона
- URL структура: `/section_order-slug/lesson_order-slug`

### 2. Структура урока
Каждый урок состоит из трёх секций:
- **Теоретический материал** — HTML контент без заголовка "Теория"
- **Тестирование** — вопросы с 4 вариантами ответов, один правильный
- **Лабораторная работа** — HTML контент, аналогичный теории

### 3. Интерактивные тесты
- Мгновенная обратная связь после выбора ответа
- Зелёная галочка для правильного ответа, красный крестик для неправильного
- Блокировка вопроса после ответа (невозможность изменить выбор)
- Сохранение прогресса не требуется
- Преобразование текстового формата с галочками (✔) в JSON

### 4. Админ-панель
- Доступ по URL `/bod`
- Авторизация одного администратора (bodryakov.web / Anna-140275)
- PHP сессии для управления авторизацией
- CRUD операции для разделов и уроков
- CKEditor 5 для редактирования контента
- Программный конвертер тестов из текста в JSON

### 5. Дизайн и интерфейс
- Material Design 3 в плоском стиле
- Mobile First подход (начиная с 320px)
- Адаптивность с точками перелома: 600px, 1000px, 1500px, 1920px
- Переключение светлой/тёмной темы
- Шрифт Roboto через Google Fonts
- Цветовая схема в оттенках серого (OKLCH)
- Максимальная ширина контента 1900px для экранов >= 1920px

## Структура базы данных

### Таблица sections
| Поле | Тип | Описание |
|------|-----|----------|
| id | INT, PRIMARY KEY, AUTO_INCREMENT | Уникальный идентификатор |
| title_ru | VARCHAR | Заголовок раздела на русском |
| slug | VARCHAR | Английский идентификатор (только маленькие буквы и дефисы) |
| section_order | INT | Порядковый номер для формирования URL |

### Таблица lessons
| Поле | Тип | Описание |
|------|-----|----------|
| id | INT, PRIMARY KEY, AUTO_INCREMENT | Уникальный идентификатор |
| section_id | INT, FOREIGN KEY | Ссылка на раздел |
| title_ru | VARCHAR | Заголовок урока на русском |
| slug | VARCHAR | Английский идентификатор (только маленькие буквы и дефисы) |
| lesson_order | INT | Порядковый номер для формирования URL |
| content | JSON | Контент урока (theory, tests, lab) |

### Структура JSON контента урока
```json
{
  "theory": "HTML контент теории",
  "tests": [
    {
      "question": "Текст вопроса",
      "answers": ["Ответ 1", "Ответ 2", "Ответ 3", "Ответ 4"],
      "correct": 2
    }
  ],
  "lab": "HTML контент лабораторной работы"
}
```

## Особенности реализации

### Технологический стек
- **Backend**: Чистый PHP 8.2.30 без фреймворков
- **Database**: MySQL с подключением через PDO
- **Frontend**: Чистый HTML, CSS, JavaScript без библиотек
- **Editor**: CKEditor 5 (CDN версия)
- **Architecture**: MVC паттерн, Front Controller

### Безопасность
- htmlspecialchars() для всего контента при сохранении
- Декодирование HTML-сущностей для блоков кода при выводе
- PHP сессии для авторизации администратора
- Hardcode credential'ов в коде (согласно требованиям)

### Обработка контента
- UTF-8 без BOM для всех файлов
- Поддержка кириллицы
- Специальные символы в коде: декодирование для отображения
- RTF импорт: копирование как plain text с ручным форматированием

### Валидация данных
- Проверка уникальности названий и slug (глобально)
- Проверка уникальности порядковых номеров (в пределах раздела)
- Проверка формата slug (только английские буквы и дефисы)
- Обязательность заполнения всех полей

### Маршрутизация
- Front Controller через index.php
- .htaccess перенаправляет все запросы на index.php
- Динамическое формирование URL из полей БД
- Обработка 404 ошибок

### Адаптивность
- Mobile First дизайн
- CSS Grid вместо Flex
- Современные CSS возможности: cascade layers, nesting, container queries
- Функции адаптивности: clamp(), min(), max()
- OKLCH цветовое пространство
